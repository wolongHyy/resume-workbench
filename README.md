# 免费简历在线制作工具

一个本地优先、免费使用的中文简历工作台。左侧编辑、右侧 A4 实时预览；粘贴简历文本即可自动识别并导入；内置高星 Skill 帮助修改简历；支持 PDF、PNG、JPG 高清导出。

## 核心差异点

### 文本一键智能导入

直接粘贴已有简历文本，自动识别基本信息、姓名、电话/手机、邮箱、求职意向、教育经历、工作经历、实习经历、项目经历、校园经历、奖项荣誉、专业技能等关键词，并按模块自动填入。无法识别为简历内容的无关文本会提示：

`非简历内容，导入失败，请导入可识别的简历内容`

### 左侧编辑，右侧 A4 实时预览

所有输入即时同步到右侧预览，无需刷新。字体大小、段落间距、模块显示顺序都可以实时调整，并随简历一起自动保存。

### 本地账号与数据隔离

每个账号的简历独立保存在 `D:\简历\users\<用户ID>\resumes.json`，密码只保存哈希值。未登录用户不能读取、保存、导入或导出简历。

### 高清 A4 导出

使用本机 Microsoft Edge 无头渲染，导出 PDF、PNG、JPG 三种格式。预览和导出使用同一份简历数据，模块顺序、字体大小、段落间距完全一致。

### 全链路文本清洗

空字段直接留白，纯 `?` / `？` 占位符自动清除，所有简历文字统一为黑色。

### 内置高星 Skill 简历优化

项目内置 `resume-coach` 高星 Skill 和 `/api/skills` 接口，支持结构化解析、事实改写、JD 匹配、导出前检查。本地 Skill 不可用时自动降级为保守建议，不影响简历编辑和导出。

## 设计说明

- 单一数据源：编辑器、预览、导入、导出共用同一个 `Resume` 状态，输入后立即更新。
- 模块化字段：支持教育经历、工作经历、实习经历、项目经历、校园经历、奖项荣誉、专业技能和两个自定义模块。
- 自定义顺序：`sectionOrder` 决定预览与导出中的模块显示顺序，上移/下移即时生效。
- 用户隔离：使用 `resume_user` httpOnly Cookie 识别当前用户，接口按用户目录读写。
- 本地优先：数据、导出临时文件和最终文件全部留在本机 D 盘，不上传云端。

## 快速开始

要求：Node.js 18+，Windows 10/11（v1.0 数据目录按 Windows 本机设计）。

```bash
npm install
npm run dev
```

开发服务默认运行在 `http://localhost:4000`，首次访问请注册账号。

## 主要技术栈

- Next.js 15 + TypeScript + React 19
- 本地 JSON 文件存储
- bcryptjs 密码哈希
- Microsoft Edge headless + sharp 高清导出

## 仓库结构

```text
app/              页面与 API 路由
components/       登录页、简历工作台
lib/              数据模型、存储、鉴权、导入识别、Skill 调用
resume-coach/     内置高星 Skill
worker/           本地辅助脚本
```
